# User Stories – Kurzschulung

One-Pager-Webseite, die das methodische Arbeiten mit User Stories erklärt und kurz schult: Standardformat, 3Cs, INVEST, Akzeptanzkriterien, Definition of Ready und Done, Aufteilen zu großer Stories – mit interaktiver Story-Werkstatt (INVEST-Check nach den Regeln der App) und Wissenscheck.

Öffnen: `index.html` direkt im Browser (keine Build-Schritte nötig).

Referenz-App: https://method-commons.github.io/user-story-app/ ([Quellcode](https://github.com/method-commons/user-story-app))
